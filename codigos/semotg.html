Guia Termux: organizar arquivos

Importante: este guia só mostra os comandos. Quem roda os comandos é o Termux. Nada aqui apaga arquivos.

Etapa 1: instalar o Python

Digite no Termux:

pkg update
pkg install python
termux-setup-storage

O último comando pede permissão para acessar seus arquivos. Toque em Permitir.

Etapa 2: criar o script

Digite:

nano organizar.py

Cole o código do script que recebeu na conversa. Depois salve com Ctrl+O, Enter e saia com Ctrl+X.

Etapa 3: prévia (não copia nada)

Digite:

cd ~/storage/downloads
python organizar.py ~/storage/downloads

Depois abra o arquivo previa_relatorio.txt na pasta Downloads e confira.

Etapa 4: copiar de verdade

Só faça isso depois de conferir a prévia:

python organizar.py ~/storage/downloads --executar

Os arquivos organizados vão para a pasta ORGANIZADO. Os originais continuam no lugar.

Erros comuns

"python: command not found": o Python não foi instalado. Repita a Etapa 1.

"Permission denied": rode termux-setup-storage de novo e aceite.

Erro vermelho com a palavra Traceback: copie a última linha e me envie.
